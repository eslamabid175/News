# News App 📰  
A modern News App built with Jetpack Compose, Offline Caching, and Ktor API.  

## ✨ Features  
✅ Offline support with RoomDB  
✅ MVI Architecture for clean state management  
✅ Ktor for efficient API calls  
✅ Coil for fast image loading  
✅ Fully tested with JUnit and Truth  

## 🛠 Tech Stack  
- **Jetpack Compose** - Declarative UI  
- **Ktor** - Networking  
- **RoomDB** - Offline Caching  
- **Koin** - Dependency Injection  
- **Truth** - Testing
